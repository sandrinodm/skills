  • Android APK Decompilation

    Acquire, verify, sandbox, and decompile Android APK/APKM/XAPK/APKS artifacts with Dockerized ADB, JADX, apktool, and apksigner.

    What it does
    • Pulls the copy Google Play installed on your own phone over wireless ADB, so you analyze exactly what users run.
    • Runs ADB, JADX, apktool and apksigner in Docker, so nothing gets installed on your machine, and keeps the network off during analysis.
    • Verifies hashes and signing certificates, and trusts an APKM, XAPK or APKS download only once its signer matches the Play copy.
    • Searches the decompiled app for endpoints, auth tokens, permissions and certificate pinning, then writes sanitized notes with a confidence label instead of committing APKs or decompiled source.
    Try asking
    • Pull com.example.app from my phone and check who signed it
    • Decompile this .xapk and list the API endpoints it calls
    Needs
    Docker, plus an Android phone with wireless debugging to pull apps. Use it only on apps and devices you own or are allowed to inspect.

    Use when working with Android APK, APKM, XAPK, or APKS files; pulling installed packages with adb; verifying Android app signatures; sandboxing jadx, apktool, apksigner, and Android platform-tools in Docker; decompiling apps; or extracting static API evidence from authorized Android apps.

  • Crisp Diagrams

    Draw clean, minimal explanatory diagrams as standalone SVG files: thin outlines, one blue accent on the idea that matters, a title that states the takeaway, and automatic dark mode.

    What it does
    • Turns a description, a Mermaid file or a whiteboard photo into one SVG that looks the same on GitHub, in Markdown, in docs and on slides, and switches to dark mode by itself.
    • Covers 31 diagram types, from architecture, auth flows and swimlanes to state machines, data models, Wardley maps, timelines and device mockups.
    • Comes with four themes: quiet outlines for docs, pastel for slides, gradients for product pages and tinted zones for trust boundaries.
    • Set your own theme: share a logo, a slide or a screenshot (or a single hex color) and it saves your brand palette to DIAGRAM.md. Every later diagram in the project follows it.
    • Checks each diagram in headless Chrome for overflowing text, overlapping labels and off-palette colors, and reviews the light and dark previews before handing it over.
    Try asking
    • /crisp-diagrams the OAuth device flow for our login docs
    • Make our diagrams match our brand. Here's our logo.
    • Redraw this whiteboard photo as a clean diagram
    • /crisp-diagrams on its own, and it asks what to draw
    Needs
    Python 3 and Google Chrome or Chromium. Reading brand colors from an image also needs Pillow, ImageMagick or the sips tool built into macOS.

  • GitHub Code Search

    Search GitHub for similar code examples using the ghx CLI, with GitHub CLI authentication and npm install checks.

    What it does
    • Turns your question into targeted GitHub code searches, narrowed by repository, language, file extension, filename or path.
    • Starts with a few results and widens the search only when they're weak.
    • Summarizes the patterns it finds across several repositories, then adapts them to your codebase's architecture and style instead of copying code.
    • Checks that the GitHub CLI is installed and signed in, and installs ghx from npm if it's missing.
    Try asking
    • How do other projects debounce input with useState?
    • Find examples of Bun.serve with WebSockets
    • Show me how open-source apps set up strict mode in tsconfig.json
    Needs
    The GitHub CLI (gh), signed in. The skill installs ghx if it isn't there yet.

Use when the user asks to find examples on GitHub, compare how other projects implement something, inspect open-source usage of a library or API, or research code patterns with ghx.

  • Product Name Finder

    Generate strategic company, product, platform, feature, and sub-brand names using a professional naming workflow inspired by David Placek's work at Lexicon Branding.

    What it does
    • Works like a naming agency: a brief, a map of the category, 8 to 15 naming territories, then 150 to 300+ candidates before it narrows anything down.
    • Scores candidates from 1 to 5 on twelve criteria, including distinctiveness, memorability, believability, trademark promise and cross-language safety, and drops the ones that fail hard.
    • Tests the finalists in context and explains the trade-offs, separating the safest pick from the one with the most upside.
    • Ends with a recommendation: a top 3, 2 backups and a wild card, plus the checks to run next with trademark counsel, domains and native speakers.
    Try asking
    • Name our AI bookkeeping tool for freelancers in Europe
    • We're renaming the company. Here's what we do, who we sell to and who we compete with.
    • Give me a quick sprint of 30 names for our new search feature
    Needs
    Nothing to install. Share a brief (what you do, audience, category, what sets you apart, tone, markets), or let it state its assumptions.
    pnpx skills add sandrinodm/skills --skill product-name-finder
    SKILL.md
    Agent description

    Generate strong, scalable company, product, platform, feature, sub-brand, or rename candidates using a professional naming workflow. Use when the user asks to name or rename a startup, company, product, app, AI product, platform, feature, service, brand architecture element, or when they request naming territories, raw name candidates, scored shortlists, naming rationale, product-name brainstorming, or final naming recommendations.
